# Vidya Residency & PG - Official Website

Official website for **Vidya Residency and PG**, a premier student PG hostel in Silapathar, Assam, located within short walking distance of SFS Silapathar, DBHS Silapathar, and Silapathar Science College.

## Features
- **Animated Splash Screen**: Features official logo with smooth auto-transition to the main page.
- **Strictly Authentic**: Built with zero fake/AI images; clean typography, custom SVG icons, and authentic branding.
- **Interactive Weekly Mess Menu**: Day-by-day meal schedule (Breakfast, Lunch, Evening Snacks, Dinner, Sunday Feast) with automatic "Today's Menu" detection and expandable 7-day table.
- **Educational Hub Proximity**: Walking distances to SFS Silapathar (200m), DBHS Silapathar (400m), and Silapathar Science College (700m).
- **Direct Calling & WhatsApp Integration**: Quick contact buttons and interactive booking/inquiry form connected to WhatsApp (+91 9954507356).
- **Fully Responsive**: Mobile-first, tablet, and desktop optimized vanilla CSS.

## Running Locally
You can run this site using any local HTTP server:
```bash
python3 -m http.server 3456
```
Then visit `http://localhost:3456` in your browser.
